# Juice Oracle

This is a set of miniature pocketfold oracles and toolkits for solo RPGs.

Includes the following features:

- Simple Y/N oracle with likeliness
- Scene transitions
- Random Events with NPC behavior
- Name generator
- Inspiration tables with word pairs, symbols, colors
- Immersion tables
- NPC Dialog tables
- Challenge / Consequence tables
- Quest Generation
- Settlement Generation
- Wilderness and Dungeon Exploration
- Treasure Generation

Its everything you need to get started, and it fits in your pocket.

## Tips

- Guidelines, not rules. There is no wrong way to play. Choose what is most fun.
- Keep the flow moving. If something doesn't make sense, reroll.
- Defer some questions for later; Answers may naturally come to you as you play.
- Be your character! Describe the situation, how you handle it, and why.
- Your actions have consequences and change the world in a meaningful way.
- Fail-forward: Every failure is a new opportunity and a challenge to overcome.
